너는 숙련된 웹 게임 개발자이자 게임 디자이너야.
아래 기획으로 HTML 파일 하나(HTML+CSS+JS 인라인, 외부 이미지·음원 파일 없음)로 
완성된 육성 시뮬레이션 게임을 만들어 줘.

## 세계관 (오리지널)
- 제목: 「별조각 위치즈」
- 하늘 위 '달의 정원'의 차기 수호자를 뽑는 시험이 열린다.
- 견습 마녀 '루나리'(주인공, 덜렁대지만 씩씩함)와 라이벌 '미엘'(우아하고 
  인기 많음)이 인간 세상의 학교에 전학 와서, 사람들의 감정에서 생겨나는 
  '감정의 별조각'을 모은다.
- 별조각 종류: 설렘(분홍), 기쁨(노랑), 우정(하늘색), 용기(주황), 
  슬픔(남색, 모으면 감점 이벤트), 반짝임(무지개, 희귀)
- 시험 기간: 30일. 30일째 밤 '달맞이 의식'에서 점수로 엔딩 결정.

## 게임 시스템
- 하루 = 아침/방과후/밤 3턴. 매 턴 행동 선택:
  수업 듣기(지력↑), 친구와 대화(매력↑, 별조각 획득 기회), 
  마법 연습(마력↑, 체력↓), 휴식(체력↑), 마을 산책(랜덤 이벤트)
- 스탯: 매력, 지력, 마력, 체력(0이면 강제 휴식)
- 학교 NPC 5명(모두 오리지널 이름/외형), 각자 호감도와 성격이 있고 
  호감도에 따라 얻는 별조각 종류가 달라짐
- 라이벌 미엘의 점수도 매일 자동으로 오르고, 화면에 비교 막대 표시
- 랜덤 이벤트 최소 12종 (분실물 찾기, 비 오는 날 우산, 축제 준비 등)
- 엔딩 최소 4종: 수호자 엔딩 / 라이벌과 공동 수호자 / 인간 세상에 남기 / 
  아쉬운 재도전 엔딩
- localStorage로 세이브/로드 (try/catch로 감싸기)

## 비주얼 스타일 (오리지널 그림, SVG/CSS로 직접 그리기)
- 2000년대 순정 만화 잡지 느낌: 파스텔 핑크·라벤더·민트, 큰 눈망울, 
  하이라이트 반짝이, 꽃잎과 별 파티클, 레이스 테두리, 리본 장식
- 캐릭터는 SVG로 그린 오리지널 디자인 상반신 스탠딩(표정 3종: 기본/웃음/당황)
- 배경 4종(교실, 하교길, 방, 달의 정원 밤하늘)을 SVG 그라데이션과 
  도형으로 표현
- 대사창은 말풍선+만화 효과선, 중요한 장면은 스크린톤 도트 패턴과 
  집중선 연출
- 별조각 획득 시 반짝이며 병에 담기는 애니메이션
- 모바일에서도 플레이 가능하게 반응형

## 사운드 (Web Audio API로 오리지널 작곡)
- 낮 테마: 밝고 통통 튀는 왈츠풍 오르골 멜로디
- 밤 테마: 몽환적인 벨 + 패드 사운드
- 효과음: 버튼 클릭, 별조각 획득(반짝 차임), 레벨업, 엔딩 팡파레
- 첫 클릭 후 재생 시작, 화면 구석에 음소거 버튼

- 바로 실행되는 완성 코드 전체를 한 파일로 출력
- 코드 상단에 게임 조작법 주석
- 텍스트는 전부 한국어
